# CPU contact runtime

The Studio grasp driver uses MuJoCo 3.3.7, distributed under Apache-2.0:
https://github.com/google-deepmind/mujoco/tree/3.3.7
https://github.com/google-deepmind/mujoco/blob/3.3.7/LICENSE

Model and contact reference:
https://mujoco.readthedocs.io/en/3.3.7/modeling.html
https://mujoco.readthedocs.io/en/3.3.7/XMLreference.html

The Python wheel retains upstream license notices. Studio calls its CPU dynamics
only. Blender handles rendering. The included adult profile is authored production
calibration; it is not medical, anthropometric or injury-prediction software.
