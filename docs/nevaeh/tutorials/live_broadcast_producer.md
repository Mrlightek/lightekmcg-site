# Live Broadcast Producer

## Prepare a show

Open **Live Studio → Prepare a show with Nevaeh**. Give the producer a title, talking points in the order you want to cover them, a destination, and an optional saved Live Studio scene. Choose **Assign show to Nevaeh**. The producer creates an opening cue, talking cards and a close, and verifies access to the scene and its prepared assets. The completed show appears under the preparation form and in the goal receipt.

## Host the show

Open the prepared show. Use **Previous cue** and **Next cue** to move at your own pace. **Freestyle** holds your place until you return to the rundown. The cues stay in the host's private browser interface. The program preview and transmission controls use the existing Live Studio capture session.

If there is a prepared scene, load it into the program preview. The package pins the scene revision. Prepare the show again if the scene changes. If the requested destination becomes unavailable, the interface selects a private test and displays the reason. Enable the camera and microphone in your browser, check the program preview, and use the existing broadcast controls to start and stop. Restream and TikTok confirmations use the existing flow.

## Assign it from Nevaeh

In Nevaeh, use `/live prepare SITE_ID {"title":"Lightek Live","brief":"What we shipped\nLive demo\nQuestions","destination":"test"}`. Add `scene_id` to use a saved scene. The producer prepares the package through Dispatch, with this guide attached to the worker run.

The current binding prepares the rundown and workspace. Browser permission, live switching, guest connections, going on air and stopping are operated from Live Studio. The [live operations contract](../../studio/live-nevaeh-contract.md) tracks the additional producer controls.
