# Memory, voice and personas

Memory is optional personal context. Action receipts are a separate audit record.

## Remember a preference

```text
/remember Preferences: Keep replies concise
```

1. Nevaeh offers the item in the thought card.
2. If the category is disabled, Allow category enables the category only.
3. Choose Remember to save the individual item.
4. Find it under Remembered; choose Forget to remove it.

Categories start disabled. Disabling a category removes its memories. Turning on a category does not automatically store every conversation. Consented memories can provide native-model context; they do not authorize actions or train a checkpoint automatically.

## Speak with Nevaeh

Use Voice to start microphone input and Speak to hear replies. The browser controls microphone permission and available speech-recognition support. Use HTTPS. Press Escape to stop listening and cancel speech. If recognition is unavailable, use the command input.

Voice can submit recognized commands, so inspect the transcription and resulting receipt. Browser speech services may be involved; this is not an offline speech recognition guarantee.

## Create a custom agent

Choose Generate agent, enter its name and identity information, and send the resulting creation instruction. Saved personas have the same worker/delegation interface as built-in agents. Use their numeric ID for an unambiguous `/delegate ID INSTRUCTION`.

The persona's instructions can shape native model drafts. Its voice/visual styling and approximate natal chart do not provide additional permissions.
