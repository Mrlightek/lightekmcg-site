# Meet Nevaeh

Nevaeh is the operating workspace for your signed-in account. Conversation, capabilities, agents, workers and application adapters share an action ledger. Her visual identity does not change your permissions.

## Your first five minutes

1. Open Nevaeh from Dashboard, then open **Guide** in Mission Control.
2. Enter `/help` to see command vocabulary.
3. Enter `/capabilities` to see what is installed. A capability button puts its command into the input; you still choose when to send it.
4. Try `susu.list` or `show my susus`. This lists Susus you organize or belong to.
5. Read the thought card and execution receipt. **Queued** means submitted; **completed** means its downstream operation finished. Structured ticket workflows additionally report verification.

```text
/help
/capabilities
/describe susu.list
susu.list
/status
```

## Choose a mode

**Converse** and **Operate** can execute recognized instructions. **Decide** and **Reflect** show proposed mutating instructions without dispatching them. Ordinary prose retrieves documentation or uses an available native model; model prose is not automatically executed as code.

## Find information without asking an external assistant

Use the Guide search, the live capability reference, `/describe CAPABILITY`, `/resources`, and the topic tutorials. The reference includes disabled or unconnected registered abilities for administrators, with their availability clearly marked. Missing input schemas are visible documentation gaps, not guessed inputs.

## Read the visual interface

The wheel is an identity visualization with approximate chart positions. Source references and execution evidence explain actual requests. Permissions and authorization do not depend on astrology. The principle labels do not represent measured numerical ethics scores.
