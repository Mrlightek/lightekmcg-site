# Lightek broadcast graphics standards

In Live Studio, open **Broadcast frame & green screen**, choose a house look, and enter the station or show name. The private frame preview updates as you edit. Use **Apply to program** to send the current frame to the program. Sample copy in the preview is for layout only.

| House look | Use on air |
| --- | --- |
| Studio Signature | Network presentation, hosts, and general live programming |
| News Desk | News bulletins, interviews, and scheduled coverage |
| Breaking News | Active breaking coverage |
| Sports Desk | Sports talk and event coverage with a score or status |
| Local Newsroom | Local reports and community programming |
| Lightek Originals | Film, documentaries, premieres, and original productions |
| Entertainment Live | Performances, culture programming, and entertainment events |
| Gamecast | Games, animation showcases, and competition coverage |
| Affiliate Station | Co-branded feeds and local station identity |
| Sponsor Credit | A clearly attributed sponsor credit, using the sponsor name and optional disclosure line |

## Create a station look

1. Start with the house look for the format you will air. Edit the name, badge, accent, panel tint, texture, and corner accents.
2. Put the main message in **Bottom headline** and the supporting line in **Second line**. Enter a manually verified score in Sports Desk or Gamecast when needed.
3. Use a unique theme name and **Save theme** to keep your variant in this browser. To distribute the branding, select the saved theme and use **Export selected look**. An operator can import the JSON in another browser or station and save it locally. Shared files carry appearance settings and branding. Each station enters its own headlines, scores, and current copy.
4. Check the actual program preview with the intended source, then review a private recording at the smallest output size used by your audience.

## On-air rules

- On the 1280 × 720 canvas, text and information plates stay at least 48 pixels from horizontal picture edges and 36 pixels from vertical edges. Only decorative corner marks extend beyond that area.
- Keep the center open. Use one primary headline and one supporting line. Font sizes stay fixed and overflowing text ends with an ellipsis.
- Put readable light text on dark plates, use automatic contrasting badge text, and confine textures to the plates. Use accent colors to communicate hierarchy without relying on color alone.
- The breaking badge signals active breaking coverage. Use a clear sponsor credit for an actual sponsorship. Add timely copy before putting either graphic on program.
- A sponsor credit is visual branding. Booked spots and delivery are managed in the advertising and channel rundown workflows.
- These looks composite in the Live Studio program and in a Live Studio contribution used by a managed channel. Unattended airings use their scheduled source media and rundown settings.
