# Business productions in Lightek Studio

## Website and PWA activation

A login is an identity. The website/application provisioning workflow creates the business's site and its PWA. Use Dashboard → Servers & Applications → create application to install a website on an authorized existing instance or a new instance. A paid hosting package uses the same Gatekeeper launch/provisioning services after verified payment. The native hosted-site bootstrap creates `LightekPwa::Application` for the site; subscription-based website provisioning does so as well.

Use Dashboard → PWA Administration to control the selected site's brand, navigation, content and enabled features. An active subscription or a database record alone is not evidence of successful DNS, HTTPS or application installation. Check the installation status and public site before sending customers there. User registration by itself does not allocate a server or a separate PWA.

## Make and release a business video

1. Open Dashboard → Studio & Broadcasting → New production. Name it and choose Landscape (website, YouTube, OTT), Portrait (TikTok, Reels, Shorts), Square (product/social), or Audio (voice/music/podcasts).
2. In Media, import your footage, audio or stills. Wait for preparation to finish, choose an item, then append it or drag it onto the timeline. Import/preparation errors keep a retry action.
3. Edit and trim clips in Edit. Color, titles, clip audio, track mixing and source media stay with this sequence. Animation, AI Studio and Music use the same production and asset library. Finished Blender shots and generated assets can be added to the edit.
4. In Deliver, review format, frame rate and quality. Format changes preserve the clips/effects but change the canvas; review framing and title placement in Edit. Share exports H.264 MP4 (video) or 16-bit WAV (audio); Master exports ProRes MOV or 24-bit WAV. OTT publication requires an MP4.
5. Choose **Save edit & get export quote**. This saves the timeline and quotes its FFmpeg assembly. **Get Blender movie quote**, inside the separate disclosure, renders the current Blender scene animation instead. The quote records an immutable export snapshot. Changing the edit requires a new quote for those changes.
6. Review the price, continue through the existing Dymond Bank checkout, and return to this Dashboard sequence's Deliver page. Rendering starts only after verified payment. Awaiting-payment snapshots remain available under Review & publish after reload; their label distinguishes them from a newly changed edit.
7. Refresh exports to see completed output or failures. Download the master or choose **Publish / schedule** for Lightek/PWA social feeds, Lightek Streaming or Octavia. Release activity shows persisted publication state. View publication opens the selected website's PWA, including when Dashboard manages another domain. External social upload can use a downloaded MP4; the download is not automatic social posting.

## Verification and remaining production work

Acceptance exercises real timeline normalization, ownership checks, persisted export snapshots and Dashboard/PWA checkout return routing. FFmpeg checks produce actual H.264 landscape/portrait/square exports, ProRes MOV and WAV masters. Browser checks run the native scripts through edit/title/format/save/quote/error recovery/publish/resumed-checkout interactions; render, payment and publication responses are fixtures there. They do not charge a card or publish to a real social account.

This release closes the Dashboard delivery gap. It does not establish complete DaVinci Resolve/Blender feature parity. Current timeline limits remain 64 clips, 16 tracks and ten minutes per assembly. Neural generation, production character motion/lip sync, native Blender execution, LiveKit networking and real social publishing require their own engine/device/account acceptance. CMS placement, campaign association and automatic external social posting are not added by the Deliver controls. Existing work is retained; these outstanding capabilities are not represented as completed.
